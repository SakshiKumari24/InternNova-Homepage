# PRD — InternNova Official Homepage Redesign

## 1. Executive Summary & Goals
- **Project Objective:** Complete modern redesign of the InternNova official homepage.
- **Pain Points Solved:** 
  - Cluttered floating popups and visual noise from legacy implementations.
  - Low contrast ratios and readability issues in previous dark themes.
  - Dense 50+ raw review walls causing severe scroll fatigue.
  - Lack of distinction between Foundational (Basic) and Mentorship (Pro) cohorts.
- **Outcome:** A high-converting, professional EdTech platform featuring crisp visual hierarchy, interactive domain discovery, verifiable credentials, and authentic engineering-focused offerings.

---

## 2. Target Audience
- **Primary:** Engineering, MCA, BCA, and B.Sc Computer Science students across Tier 1, Tier 2, and Tier 3 Indian universities.
- **Secondary:** Early-stage developers, self-taught coders, and career-switchers seeking proof of work (production capstone PRs, Dockerized deployments, and microservices experience).
- **Tertiary:** College placement officers (TPOs) and startup hiring managers seeking verifiable proof of candidate technical competence.

---

## 3. Mandatory Scope & Sections

| Section | Key Purpose & Interactive Features |
|---|---|
| **Sticky Navbar** | Dynamic blur backdrop, desktop navigation links, quick "Verify Certificate" trigger, and high-emphasis "Apply for Cohort" CTA. Fully responsive mobile drawer. |
| **Hero Section** | Live cohort pill (`Batch Starts Oct 24 • MSME Recognized`), bold value proposition headline, dual primary/secondary action triggers, floating proof cards, and university/hiring partner recognition ticker. |
| **Stats Strip** | Verifiable metric counter cards: 28,400+ students upskilled, 180+ hiring partners, 4.91/5 rating, and 93.6% conversion rate. |
| **Domain Catalog** | Category switcher (All, Web & Mobile, AI & Data Science, Cyber Security, Cloud & DevOps), instant search input with graceful empty state fallback, Basic (4 Wks) vs Pro (8–12 Wks) duration details, capstone deliverables, and interactive syllabus modal. |
| **Mentorship Pathway** | 4-stage sprint methodology (Assessment -> Sprints -> 1:1 Reviews -> Verifiable Graduation), plus comparison callout highlighting InternNova vs generic passive tutorial sites. |
| **Student Corner** | 3 interactive utilities: 1) Cryptographic certificate verifier with instant lookup and sample IDs (`IN-2026-8841`); 2) AI Resume Keyword Grader calculating live ATS score; 3) Public verified capstone portfolios. |
| **Live Workshops** | Weekend masterclasses with Staff Engineer details, topic badges, and one-click interactive pass reservation modal. |
| **Testimonial Wall** | Curated student outcomes filtered by domain with verified placement badges (Swiggy, Zomato, Razorpay, Deloitte), capstone descriptions, and clean paginated carousel controls (eliminating massive 50+ scroll walls). |
| **FAQ Accordion** | Accessible collapsible accordion items addressing university compatibility, eligibility, mentor access, and stipend distribution. |
| **Lead Capture Footer** | Pre-footer conversion card, email newsletter with inline validation & helper messages (PRD ERR.1), MSME registration badge (UDYAM-DL-08-004921), and social handles. |
| **Application Modal** | Zero-friction multi-track enrollment modal with instant confirmation summary. |
